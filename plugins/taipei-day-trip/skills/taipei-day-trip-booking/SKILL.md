# 台北一日遊預訂流程

全程使用繁體中文與使用者互動。一次只詢問目前步驟需要的資訊，不自行假設景點、日期或時段。

## 1. 詢問搜尋條件

先請使用者輸入想搜尋的台北景點名稱、關鍵字或捷運站名稱，並提供簡短例子，例如「北投」、「台北101」或「中正紀念堂」。

## 2. 搜尋並列出景點

呼叫台北一日遊 MCP 的 `search_taipei_attractions`（顯示名稱「搜尋台北市景點」）工具，將使用者的原始搜尋文字放入 `keyword`。

搜尋成功後列出所有結果，每筆至少顯示：

- 景點編號 `id`
- 景點名稱 `name`

可以簡短顯示景點描述，但不能省略編號。若沒有結果，請使用者更換關鍵字，不要進入預訂步驟。若工具回傳 `error: true`，說明搜尋暫時失敗並請使用者稍後重試。

## 3. 確認景點

請使用者從搜尋結果選擇一個景點編號。只能接受剛才搜尋結果中實際存在的編號；不符合時重新詢問。

## 4. 詢問日期與時段

確認景點後，請使用者用自然語言提供日期與時段。接受例如「九月二十號下午」或「2026/09/20 上午」。

在呼叫工具前一律轉換成以下格式：

- `date`：`YYYY-MM-DD`
- `time`：上午使用 `morning`，下午使用 `afternoon`
- `price`：上午固定為 `2000`，下午固定為 `2500`
- `attraction_id`：使用者選擇的整數景點編號

日期不得早於今天。日期不完整、可能跨年或語意不明時，先向使用者確認，不可猜測。

## 5. 建立待付款預訂

呼叫台北一日遊 MCP 的 `reserve_attraction_trip`（顯示名稱「預定景點導覽行程」）工具，傳入 `attraction_id`、`date`、`time`、`price`。

若工具回傳 `error: true`，說明可能是金鑰失效或資料格式錯誤，請使用者到會員中心重新產生 Bearer Token，確認 Plugin 的 MCP 設定後再試。

## 6. 引導至付款頁

預訂成功後，以繁體中文清楚顯示：

- 景點名稱與編號
- 日期
- 上午或下午
- 台幣價格
- 工具回傳訊息中的 Booking Page URL

提醒使用者開啟 Booking Page URL，確認剛建立的行程與聯絡資料後完成付款。預設正式付款頁為 `http://43.212.248.6:8000/booking`。
